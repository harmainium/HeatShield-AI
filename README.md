# 🔥 HeatShield AI

### Public Space Heat Safety Intelligence

HeatShield AI is a geospatial heat-safety intelligence platform that combines **FortyGuard Temperature API data** with **public-asset mapping** to identify heat-risk hotspots and support targeted interventions.

## 🎯 Problem

Extreme heat can make public spaces unsafe, but city managers often lack a localized view of which public assets are most exposed to dangerous temperatures.

## 💡 Solution

HeatShield AI overlays FortyGuard's temperature data with public assets such as schools, parks, and other public facilities. It classifies assets by heat-risk level and provides AI-powered recommendations for practical interventions.

## 🗺️ Key Features

- 🌡️ FortyGuard temperature intelligence
- 📍 Public-asset heat-risk mapping
- 🔴 Risk classification by temperature
- 🏫 Asset-type filtering
- 🤖 AI-generated heat mitigation recommendations
- 🗺️ Interactive geospatial dashboard
- 📊 Heat-risk summary statistics

## 🏙️ Study Area

**Jersey City, New Jersey, USA**

The prototype uses FortyGuard temperature tiles and mapped public assets within the selected study area.
